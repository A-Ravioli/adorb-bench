# ✨ Adorb Bench - Kaomoji Battle Arena
the true test of agi

A delightful Next.js app that pits AI models against each other in a battle of cuteness! Generate adorable kaomoji (Japanese text emoticons) from different AI models and vote on which one is cuter.

## 🎯 Features

- **Side-by-Side Comparison**: Compare kaomoji generated by two different AI models simultaneously
- **Multiple Models**: Choose from popular models like Claude, GPT-4, Gemini, Llama, and more
- **Interactive Voting**: Vote for the cuter creature and see your rankings update in real-time
- **Leaderboard**: Track which AI models generate the cutest kaomoji with win rates and statistics
- **Beautiful UI**: Modern, playful design with gradients and smooth animations
- **Local Storage**: All rankings are saved locally in your browser

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- An OpenRouter API key ([get one here](https://openrouter.ai/))

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd adorb-bench
```

2. Install dependencies:
```bash
npm install
```

3. Set up your environment variables:
```bash
cp .env.example .env
```

4. Add your OpenRouter API key to `.env`:
```
OPENROUTER_API_KEY=your_actual_api_key_here
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

5. Run the development server:
```bash
npm run dev
```

6. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎮 How to Use

1. **Select Models**: Choose two different AI models from the dropdown menus
2. **Generate**: Click the "Generate Creatures" button to create kaomoji from both models
3. **Vote**: Click "This one is cuter!" under your favorite creature
4. **Repeat**: Generate more rounds to build up the leaderboard
5. **View Stats**: Scroll down to see which models are winning the cuteness battle!

## 🛠️ Tech Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **API**: OpenRouter (multi-model AI gateway)
- **Storage**: LocalStorage for rankings

## 🎨 Customization

### Adding New Models

Edit `app/constants.ts` and add models to the `AVAILABLE_MODELS` array:

```typescript
export const AVAILABLE_MODELS: Model[] = [
  { id: 'your/model-id', name: 'Display Name' },
  // ... more models
];
```

### Changing the Prompt

Edit the `SYSTEM_PROMPT` in `app/api/generate/route.ts` to adjust what kind of kaomoji are generated.
